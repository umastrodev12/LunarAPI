# 🌙 LunarAPI

**An Unnoficial Lunar Client API written in Python!**

## 📦 Usage

### Logs

```python
    import lunarapi
    from lunarapi import logs

    lunar = LunarAPI()

    lunar.startLogs() # Start Logs Monitoring

```

### Start API

```python
import lunarapi
from lunarapi import LunarAPI

lunar = LunarAPI()

lunar.start()
```
